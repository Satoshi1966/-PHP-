# ジャンルしりとり PHP版 1.0

シンフリーサーバー向けのPHP＋JavaScript版である。Tomcat・Java・Composer・DBは不要である。
PHPのプログラムはpublic/index.php、private/Game.php、private/config.phpの3ファイルにまとめた。

## 動作環境

PHP 8.2以降、mbstring・intl・session・JSON拡張、ローカルファイルの読み書きとflockが必要である。
サーバーパネルでPHP 8.3以降を選択し、HTTPSのURLで使用する。実サーバーの拡張・権限は設置時に確認する。
共有サーバーのPHP実行環境を使用する。サーバーへの常駐プロセスは不要である。

## 機能

- 映画、歴史上の人物、魚、日本のロボットアニメ、昭和のヒット曲・歌手名の5ジャンル。初期辞書270語である。
- CPU対戦。「やさしい」は再使用可、「ふつう」は対戦内の使用済み語と自分の過去回答を再使用不可とする。
- 正式名称・読み・別名で回答する。カタカナ・半角カナを正規化する。略称も正式名称の読みで判定する。
- 小文字は大文字に置換し、末尾の長音は直前の文字として扱う。「ん」で終われば敗北する。
- 30秒制限。毎秒の表示更新は行わず、残り10秒で一度通知する。時間切れ時にはパス・ギブアップを表示する。
- 即時パス、ギブアップ、セーブ中断・再開、戦績、ジャンル別の自分の回答履歴リセット。
- ID・パスワード登録とログイン。別端末でも同じIDの記録を利用できる。パスワードはハッシュ化する。
- フォームから名称・読み・別名を追加する。追加辞書は全利用者とCPUで共有する。
- 同じ名称・別名の重複をジャンル・種別ごとに拒否する。昭和では曲名と歌手名を分ける。
- 追加語は全体5000件、1人1日100件までである。自動的に映画の実在や昭和の曲かどうかを検証する機能はない。

## 保存と対戦

private/runtime/data.jsonへユーザー・回答履歴・対戦・追加語・戦績を保存する。
読込から更新までdata.lockを用いて排他制御し、一時ファイルを置換する。
保存失敗時は元のJSONを残す。破損データは上書きせずエラーとして停止する。
回答・パスは自動保存される。中断ボタンを押した場合は時計を止め、再開時に30秒を与える。
メニュー表示・ログアウト・ブラウザーを閉じる操作だけでは時計を止めない。
1アカウントにつき進行中の対戦は1件である。別タブ・別端末の古い回答は対戦IDとrevisionで拒否する。
「ふつう」のプレイヤー履歴には本人の正解回答を記録する。CPUの過去対戦の回答は個人履歴へ記録しない。
追加しただけでは回答にならない。辞書追加中も時計は進むため、必要なら先にセーブ中断する。
追加語によって中断セーブは無効にならない。初期words.csvを書き換える場合は、進行中の対戦を終了してから行う。
累積履歴リセットは進行中・中断中の対戦がないときだけ実行できる。

## ローカル起動

XAMPPではApacheを起動し、htdocs配下へGenreShiritoriPHPを配置して、
http://localhost/GenreShiritoriPHP/public/ を開く。
php.iniでextension=intl、extension=mbstringが有効か確認し、変更後はApacheを再起動する。
privateディレクトリをURLで開いた場合に403で拒否されることを確認する。

PHP CLIがある場合はプロジェクト直下で次を実行する。

```sh
php -S localhost:8000 -t public
```

開発用サーバーはローカル確認専用である。公開時はレンタルサーバーのApacheで実行する。

## 運用範囲

少人数の授業・試用公開を対象とする。JSON全体をロックする構成なので、大人数での運用時はDB移行を検討する。
アカウントのパスワード再発行、管理画面、追加辞書の編集・削除、Java版セーブの取込は今回の対象外である。
ID・パスワードを忘れた場合の自動復旧はできない。表示名以外の個人情報は入力しない運用を想定する。
Java版とはデータ形式が異なるため、初期辞書のみ共通とし、プレイヤー登録から開始する。
1対戦2000履歴、全保存データ30MBを上限とする。通常の試用範囲を超えた場合は管理者が容量を確認する。
